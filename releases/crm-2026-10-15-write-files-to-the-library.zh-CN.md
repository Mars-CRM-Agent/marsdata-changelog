# 写入资料库

> **预览** · 2026-10-15 · `0.1.1.5585`
> 以下功能目前处于预览阶段，尚未正式上线。

将 Mars 的输出保存为资料库中的 Markdown、文本或 JSON 文件。

Mars 可将 Markdown、文本和 JSON 文件写入资料库。你可以在富文本预览中打开，也可以直接打印。

生成的结果集中保存，便于阅读或打印。
