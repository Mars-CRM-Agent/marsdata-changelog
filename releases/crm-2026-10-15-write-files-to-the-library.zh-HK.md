# 寫入資料庫

> **預覽** · 2026-10-15 · `0.1.1.5585`
> 以下功能目前處於預覽階段，尚未正式上線。

將 Mars 的輸出保存為資料庫中的 Markdown、文本或 JSON 文件。

Mars 可將 Markdown、文本和 JSON 文件寫入資料庫。你可以在富文本預覽中打開，也可以直接打印。

生成的結果集中保存，便於閲讀或打印。
