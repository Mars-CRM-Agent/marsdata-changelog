# Find any line, act on any answer

> **Preview** · 2026-10-17 · `0.1.1.5950`
> These features are available in the preview version and have not been generally released.

The longer the chat, the harder it is to find that one line.

Find in chat searches the conversation you have open. The answer menu now holds branching, read aloud with pause, a 15-second skip and speed control, model switching, retry and web search. No scrolling to find a line, no remembering where each action lives.

Find what you need in a long chat, and do anything with an answer from one menu.
