# Grouped personal memory

> **Preview** · 2026-09-30 · `0.1.1.3581`
> These features are available in the preview version and have not been generally released.

Personal Memory now groups what Mars knows about you under one heading per topic.

Basic details, contact info and the facts Mars learned share one card when they carry the same name. Empty fields no longer take up a row, and they come back while you edit.

One place per topic, with nothing empty in the way.
